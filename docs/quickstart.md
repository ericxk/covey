# 五分钟上手

Covey 是飞书里的个人 Agent：你在飞书私聊自己的机器人说一句话，它在你自己的机器上调用 Claude Code、Codex 或 Antigravity 去做，做完把结论和产物发回飞书。每件事是一个话题，可以接着追问；任务在自己的进程里跑，机器人重启也不打断。

这一页写给刚装好、想知道怎么用的人，你问管家“看板在哪”“怎么开记忆”时，它也先读这一页。每个功能的细节在[使用指南](usage.md)。

## 装

前提：机器上已装好并登录了 Claude Code、Codex 或 Antigravity（任一个；管家，也就是私聊里直接跟你对话的那一层，默认用 Claude Code，没有它时 `./install` 新装就让它用调通的 Codex 或 Antigravity，专项照常开），Linux 或 macOS，Python 3.10+，手机飞书扫一次码。

```bash
git clone https://github.com/ericxk/covey.git && cd covey
./install
```

扫码的人就是机器人的主人。装完终端会等你在飞书里发第一句话，收到回答才结束。前提、每一步做了什么、选项和装不上怎么办见[安装](install.md)。

## 第一句话

1. 私聊里第一张是欢迎卡：这台机器启用了哪些 Harness、默认工作区在哪；点示例旁的「发这句」就直接开始。
2. 发一句「看看当前工作目录里有什么」。你的消息上出现表情就是收到了。管家能直接答的直接答，要动手的开一个话题挂在你这句话下面，做完把结论带回私聊。没有管家时（比如管家选过的 Harness 后来没启用）：每条消息开一个话题，先出启动卡，点「开始任务」。
3. 输入框上方是机器人菜单：「看板」看现在等你、停住、在做的事，「用量」看本周用量，「设置」在「配置」一页改新话题、管家、专项负责人用的模型和运行方式，另几页改工作区和群。

## 它特别在哪

几件一般的聊天机器人做不到、Covey 默认就有的事。你问管家“你能做什么”“你和别的有什么不一样”时，它照这一节说。

1. **管家先接住每句话**：私聊顶层说一句，管家能答的直接答；要动手的开成话题，挂在你那句话下面去做，做完把结论带回私聊顶层。不用先想“开哪个会话”，几件事可以同时交出去。
2. **长活交给专项和负责人**：跨几天、要拆成几个话题的事，管家开成专项，交给一位负责人：它拆活、派给话题，话题做完一轮就接着往下推；停住了、要你拍板时才来问你。私聊里一张专项卡写着进度。
3. **换引擎不断上下文**：话题做到一半想换 Harness（比如 Claude Code 换成 Codex）、换模型或工作区，点任务卡上的「换配置」。原模型先写一份交接摘要，连同最近的问答交给新模型，完整记录放在文件里；下一张任务卡上写着从什么换到什么，点开就是交接摘要。
4. **重启不断任务**：每个任务在自己的进程里跑，机器人重启、升级都不打断在跑的任务；碰上限流或临时故障停下的，到点自动接着做，任务卡上写着几点继续。
5. **说一次就记住**：你在话题里说“以后都……”“别再……”，这一轮结束后记下，答案卡底部露一行：点“不对”撤销；处处适用的话它会同时问你要不要提到全局（点「采纳」）；让它“记一下”的事也记下。菜单「设置」的「记忆」里能看数、处理待审核，逐条管理去网页的「记忆」。
6. **要你定的事不会漏**：要你拍板的都是问题卡，进菜单「看板」的“等你”；答完收成一行，写着你选了什么、交给了哪一轮。
7. **能退**：Claude Code 的话题能「回退」上一轮，对话和改过的文件一起退。

## 日常怎么用

| 想做什么 | 怎么做 |
| --- | --- |
| 开一件新事 | 在私聊顶层发一句话 |
| 接着追问 | 在那个话题里直接回复 |
| 任务在跑时改主意 | 在话题里直接发：送进正在跑的任务，卡上写“已补充到这一轮，不另开一轮”；送不进去时排成下一轮，卡上写原因 |
| 模型要你定 | 问题卡上点一个选项；只有一个待答问题时，也可以直接在话题里回复 |
| 停下、重来 | 任务卡上点「停止」；失败了卡上有「检查并继续」 |
| 换模型或工作区 | 任务卡上点「换配置」；以后新话题默认用什么，在菜单「设置」的「配置」页“新话题”一段改 |
| 看全局 | 菜单「看板」，再点一次收起 |
| 让它记住一条做法 | 对管家说“以后都……”“记住……”，它记下来，之后每一轮都带上；在话题里说的只管那个话题，要每个话题都带就到网页「记忆」里提到更大的范围；说“忘掉那条……”删掉 |
| 让群里的人也能用 | 在群里 @ 机器人，私聊里会来一张卡问你，点「启用」 |

## 常被问到的

### 看板在哪

在机器人菜单里，叫「看板」，每个部署都有，早晚汇总关了也有。菜单里还没有这一项时（应用是老版本建的），私聊里的「飞书应用待补」卡会补上。看板写的是现在的状态；早晚汇总是到点发来的另一张卡，写这段时间发生了什么。见[看板](usage.md#看板)。

### 怎么开记忆

记忆默认就开着，不用开：你在话题里说的长期要求一轮结束后记下，答案卡底部露一行，点“不对”撤销；“记一下……”这种具体的事也记下（知识条目，同样默认开）；菜单「设置」里有「记忆」标签。不想要的话，部署的人在服务清单里设 `COVEY_MEMORY=0`（知识条目是 `COVEY_KNOWLEDGE=0`），再重新注册（照[改开关三步](configuration.md#改开关三步)做，只 restart 不够）。关了记忆，对管家说的“以后都……”也照样记下，见上表。新机器人怎么装见[安装](install.md)，细节见[配置 · 记忆](configuration.md#记忆)。

### 还有哪些功能、开着没有

看菜单、Pin 和卡上有没有对应的东西就知道，对照表见[有没有这个功能](usage.md#有没有这个功能)。默认开着的、推荐打开的和怎么开关见[开关速查](configuration.md#开关速查)。常问的几个：

- 「手上的事」：私聊里置顶一张卡，原地更新等你、在做、刚结束的事。默认开，`COVEY_PINNED_OVERVIEW=0` 关。
- 早晚汇总：每天 09:30 和 21:30（北京时间）在私聊发一张汇总卡。默认开，`COVEY_DIGEST_TIMES=off` 关。
- 想把协作也打开（演示、截图）：[演示套餐](configuration.md#演示套餐)，新装用 `./install --showcase`，装好的用 `covey_service.py set --preset showcase`。
- 代答：替你回复白名单里的人，要带发送器的扩展，见[代答](proxy.md)。

### 别人私聊我的机器人会怎样

机器人只处理你本人，和你在群里开放过的成员。别人私聊它，只会收到一句“这是你的个人助手，只处理你的消息”，同一个人每天最多一次；部署设了安装说明的链接（`COVEY_INVITE_URL`）时附在后面。想用的同事各自装一个。

### 机器人不回

- 先看你的消息上有没有表情、话题里有没有卡：有就是收到了，在做。
- 在服务运行的代码目录里查服务在不在：`python3 -B bin/covey_service.py status --state-dir <状态目录>`。状态目录在哪见[数据目录](operations.md#数据目录)。
- 日志是状态目录里的 `bridge.log`，被挡下的消息各有一行 `ignored message … reason=…`。按现象查见[排障](troubleshooting.md)。

### 怎么升级

`./install` 装的机器人，在 clone 下来的仓库里运行 `scripts/upgrade.sh`（先加 `--dry-run` 看看）：它取上游的新提交、做部署前检查，再重启机器人，在跑的任务不中断。步骤和手工部署见[升级与部署](deploy.md#日常升级)。

### 怎么重启

`python3 -B bin/covey_service.py restart --state-dir <状态目录>` 只换机器人进程，在跑的任务不停，重启那几秒里点卡片和发消息没有反应。改了环境变量要重新注册，restart 不会读新的变量。不要在任务里 `stop` 服务：停了以后飞书里没有谁能让它再起来，只能到机器上 `start`。见[日常操作](operations.md#日常操作)。

## 一定要知道的边界

- 任务在你的机器上、以你的权限和凭据运行：文件、git、模型额度、飞书机器人的身份。
- 群里开放给成员后，成员 @ 它开的任务同样跑在你的机器上、用你的额度，群里的人都看得到卡片和答案。只在信得过的群里开放。
- 同一个目录里同时跑几个话题会一起改文件；要分开就在启动卡的运行方式里选[独立 worktree](usage.md#原目录与独立-worktree)。
